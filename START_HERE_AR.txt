بوابة مواقيت مساجد شيفلد - النسخة المجانية
=====================================

1. افتح README_AR.md واقرأ خطوات النشر.
2. أنشئ مستودع GitHub مجانيًا عامًا اسمه sheffield-masjid-times.
3. ارفع ملفات المشروع إلى الفرع main (بما فيها مجلد .github المخفي).
4. Settings > Pages > Source > GitHub Actions.
5. Actions > Publish Sheffield mosque times (free) > Run workflow.
6. افتح الرابط الذي يظهر لك في Settings > Pages.

لا ترفع ملف ZIP نفسه إلى المستودع: فك الضغط وارفع محتويات المجلد.
لا تنشر الموقع للمصلين كمصدر معتمد قبل مراجعة أوقات المساجد وموافقتها على إعادة نشر بياناتها.
الاستضافة وتحديث البيانات باستخدام GitHub Pages وGitHub Actions متاحان بالمجان في المستودعات العامة ضمن شروط الخدمة.
